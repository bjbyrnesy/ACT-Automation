# Repository changes — November 19, 2026

## Containerlab deployment and onboarding

- Added explicit Docker and Podman runtime selection for deployment. Onboarding discovers the lab across accessible Docker and rootless or rootful Podman stores, then uses the selected store for device commands. ([PR #3](https://github.com/bjbyrnesy/ACT-Automation/pull/3))
- Kept valid cached CVaaS enrollment tokens and added a prompt when a cached token is missing, expired, or invalid. Tokens entered at the prompt are used for that run and are not saved to `.config`. ([PR #5](https://github.com/bjbyrnesy/ACT-Automation/pull/5))

## Topology layout

- Arranged backbone routers above the site-specific border leaves, spines, leaves, and member leaves. Member leaves are centered beneath their connected leaf pairs.
- Generated explicit core and site groups for the VS Code Containerlab Topology Viewer. Deployment copies viewer annotations while preserving existing saved layouts. ([PR #4](https://github.com/bjbyrnesy/ACT-Automation/pull/4))
- Added a saved `dsg-demo-v2` viewer annotation and updated ignore rules for generated topology and configuration artifacts.

## Topology definition and support files

- Changed generated topology definitions to readable containerlab YAML with explanatory comments, `INTFTYPE: et`, and matching `et` data-plane links.
- Added configurable management gateway, address range, bridge, and MTU while retaining the existing default management subnet. Nodes receive static management addresses.
- Generated a shared cEOS startup template and per-node `.eos` identity files with deterministic serial numbers and system MAC addresses. Deployment stages the required support files locally or on the remote host and refuses to overwrite conflicting files; earlier `.txt` identity files remain supported.
- Updated documentation and included the license for containerlab's cEOS template. ([PR #6](https://github.com/bjbyrnesy/ACT-Automation/pull/6))

The topology format was checked with 46 automated tests and a containerlab dry run. Live deployment and device identity persistence with the new format have not yet been verified.
